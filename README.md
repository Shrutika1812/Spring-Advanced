# Spring Advanced

A practical Spring and Spring Boot concept lab with real Java implementations.

## Sections
- 01-Spring-Core — IoC, DI, lifecycle, scopes, configuration, profiles, events
- 02-Spring-Boot — auto-configuration, properties, logging, Actuator
- 03-REST-APIs — DTOs, validation, exceptions, pagination, filtering, versioning
- 04-JPA-Hibernate — mappings, relationships, transactions, queries, N+1, locking
- 05-Spring-Security — authentication, authorization, password hashing, JWT, method security
- 06-Advanced-Backend — caching, Redis, async, scheduling, messaging, idempotency, rate limiting
- 07-Testing — JUnit, Mockito, MockMvc, integration testing, Testcontainers
- 08-Production-Engineering — Docker, microservices, resilience, observability, CI/CD

The repository contains actual source/configuration files, not README-only placeholders.
